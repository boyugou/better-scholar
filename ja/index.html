どの論文でも自分の立ち位置がわかる

Google Scholar のプロフィール向けの Chrome 拡張機能です。各論文に著者としての役割と掲載先の CCF / CORE ランクを表示し、その結果を 1 つの表にまとめます：「CCF-A の筆頭著者論文 4 本」。

インストール GitHub で見る

無料・オープンソース · Chrome および他の Chromium 系ブラウザ対応 · 30 言語に対応

試してみる

役割をオン・オフすると、実際のページと同じようにサンプルのプロフィールも変わります。

役割ごとに色分けされた全論文

筆頭著者、共同筆頭著者、第二著者、最終著者の行にそれぞれ色が付き、著者欄ではあなたの名前が目立つように示されます。

CCF と CORE のランク

各掲載先の横に CCF 2026 と ICORE 2026 のランクを、どの規則で一致したかとともに表示します。判定できない掲載先には印を付けず、推測もしません。

役割 × ランクの表

セルを選ぶと該当する論文だけを一覧にできます。集計や一覧をコピーして、業績書や研究助成の申請書にお使いいただけます。

受賞と発表

ベストペーパー、時の試練賞、Oral・Spotlight・Highlight を、著者自身の記述と、7,000 件を超える論文の公式受賞ページから集めています。

途切れた著者リストを補完

Scholar は長い著者リストの後ろの著者を省略します。ワンクリックで論文ページから読み取り、許可すれば Semantic Scholar からも補完します。

重複エントリーの統合

オンにすると、同じ論文が 2 回載っているエントリーが 1 件にまとめられ、被引用数は合算されます。

好みに合わせて調整

表示する項目を選び、色を自分好みに変え、Scholar のページで不要な部分を非表示にできます。

設計段階からプライバシー重視

アカウント不要、アクセス解析なし、トラッキングなし。すべての計算はブラウザ内で行われ、ランクの一覧は拡張機能に同梱されています。

インストール

  1. GitHub からプロジェクトをダウンロードし（緑色の「<> コード」ボタンから「ZIP をダウンロード」）、解凍します。
  2. chrome://extensions を開き、「デベロッパー モード」をオンにします。
  3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、src フォルダーを選びます。その後、任意の Google Scholar プロフィールを開きます。

Chrome ウェブストアへの掲載も予定しています。Edge、Brave などの他の Chromium 系ブラウザでも同じ手順で使えます。

限界について

ランクは発表時点のものではなく現在のリストに基づいており、CCF のリスト自体も評価を目的としたものではないと明記しています。拡張機能は掲載先を推測しません。判定できないものは印を付けず、一覧で示します。
