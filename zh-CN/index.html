你在每篇论文中的角色与发表场所等级

一款免费的 Chrome 扩展，面向 Google Scholar 个人主页。它按你的作者角色为每篇论文着色，显示其发表场所的 CCF 和 CORE 等级，并用一张表统计你的论文。

它还能做什么

奖项与报告

最佳论文、时间检验奖，以及 Oral、Spotlight 或 Highlight 报告的标签。数据来自作者本人的说明和官方奖项页面。

完整的作者列表

Scholar 会用“…”省略较长的作者列表，这可能会隐藏你的角色。点一下，即可从 Scholar 的论文页面读取完整列表。

合并重复条目

Scholar 有时会把同一篇论文列出两次。打开这个开关后，它们会合并为一条，并把引用数相加。

自定义布局

面板的每个部分都有各自的开关。可以选择颜色、各部分的顺序，以及为它们取你自己的名字。

保护隐私

无需账号，没有分析统计，也没有追踪。所有工作都在你的浏览器中完成，等级列表就包含在扩展里。

30 种界面语言

扩展支持你的语言。它还可以用你选择的语言打开 Scholar 本身。

试用设置页面

这是扩展真正的设置页面。改动一项设置，预览随之变化。将鼠标指向预览中的某个部分，即可隐藏、移动或重命名它。

跳过演示

你的更改只保存在这个浏览器中。

用运算符搜索

在个人主页上按 / 键，即可搜索其全部论文。在搜索词中加入运算符，即可筛选列表。

cites:>100 cites:>=50 cites:<10

引用数

引用数高于或低于某个数字的论文。

ccf:a ccf:b core:a*

等级

发表在指定 CCF 或 CORE 等级场所的论文。

role:first role:last role:cofirst

角色

你是第一作者、共同第一作者、第二作者或末位作者的论文。

year:>=2020 year:2023 age:<5

年份

发表于某一年之前、之后或当年的论文，或近几年发表的论文。

has:award has:talk

奖项与报告

获得最佳论文奖或时间检验奖的论文，以及有 Oral、Spotlight 或 Highlight 报告的论文。

Escape

全部清除

按一个键即可清除搜索、选中的单元格和所有筛选条件。

安装

  1. 从 GitHub 下载项目：点击绿色的“代码”按钮，再选择“下载 ZIP”。然后解压文件。
  2. 打开 chrome://extensions，并开启“开发者模式”。
  3. 点击“加载已解压的扩展程序”，选择 src 文件夹。然后打开一个 Google Scholar 个人主页。

Edge、Brave 及其他 Chromium 浏览器的安装步骤相同。之后可能会有 Chrome 应用商店版本。

局限

  • 等级取自当前的名录。论文发表那一年，其发表场所的等级可能不同。
  • CCF 表示，其名录不应作为学术评价的依据。
  • 它从不猜测。无法确定等级的发表场所不显示标签，并会列在面板中。
