即时搜索与查询运算符

在 Scholar 个人主页的任意位置按 / 键，即可一次性搜索整个列表。

cites:>100 cites:>=50 cites:<10

引用数阈值

输入任意数字，保留引用数高于或低于该值的论文。

ccf:a ccf:b core:a*

期刊会议等级

只显示发表在 CCF 或 CORE 评级的会议和期刊上的论文。

role:first role:last role:cofirst

作者角色

按第一作者、共同第一作者、第二作者或末位（资深）作者筛选。

year:>2020 year:>=2021 year:<=2015

发表年份

筛选在所选年份之后、之前或期间发表的论文。

has:award has:talk

奖项与报告

查找 Best Paper、时间检验奖、Oral、Spotlight 和 Highlight 论文。

Escape

一键重置

一次性清除所有搜索、表格选择和筛选条件。

每篇论文，按你的角色着色

第一、共同第一、第二和末位作者各对应一种颜色，你的名字会在作者列表中被标出。

CCF 与 CORE 等级

每个场所旁显示 CCF 2026 和 ICORE 2026 的等级，并注明匹配所依据的规则。无法确定的场所保持不标：绝不猜测。

角色 × 等级表

点击任一单元格即可只列出对应论文，并可复制汇总或列表，用于简历或基金申请表。

奖项与报告

最佳论文、时间检验奖，以及 Oral、Spotlight、Highlight，数据来自作者本人的说明，以及超过 7000 篇论文的官方奖项页面。

补全被折叠的作者列表

Scholar 会隐藏长作者列表的末位作者。点一下即可从论文页面读取，若你允许，也可从 Semantic Scholar 读取。

合并重复条目

开启后，同一篇论文的重复条目会合并为一条，引用次数相加。

按你的需要定制

选择显示内容，自选颜色，隐藏你不需要的 Scholar 页面部分。

设计上即保护隐私

无需账号，没有分析统计，也没有追踪。所有计算都在你的浏览器中完成，等级列表随扩展一同发布。

安装

  1. 从 GitHub 下载项目（点击绿色的“代码”按钮，再选择“下载 ZIP”），然后解压。
  2. 打开 chrome://extensions，并开启“开发者模式”。
  3. 点击“加载已解压的扩展程序”，选择 src 文件夹。然后打开任意一个 Google Scholar 个人主页。

之后可能会上架 Chrome 应用商店。Edge、Brave 及其他 Chromium 浏览器的安装方式相同。

坦诚说明局限

等级采用的是当前的名录，而非发表时的等级；CCF 名录本身也声明它不是学术评价。扩展从不猜测场所：无法确定的会列出，但不做标记。
