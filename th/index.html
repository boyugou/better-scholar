ดูตำแหน่งของคุณในทุกบทความ

ส่วนขยาย Chrome สำหรับโปรไฟล์ Google Scholar แสดงบทบาทการเขียนของคุณและอันดับ CCF / CORE ของแหล่งตีพิมพ์ในแต่ละบทความ แล้วสรุปผลในตารางเดียว: “บทความ CCF-A 4 เรื่องที่คุณเป็นผู้เขียนคนแรก”

ติดตั้ง ดูบน GitHub

ฟรีและโอเพนซอร์ส · Chrome และเบราว์เซอร์ Chromium อื่น ๆ · 30 ภาษา

ลองใช้หน้าการตั้งค่าจริง

นี่คือหน้าการตั้งค่าของส่วนขยายเอง ทำงานอยู่ที่นี่ ลองเปิดหรือปิดสวิตช์ แล้วตัวอย่างจะเปลี่ยนตาม เลื่อนเมาส์ไปที่ตัวอย่างเพื่อซ่อน ย้าย หรือเปลี่ยนชื่อส่วน และดับเบิลคลิกที่ส่วนเพื่อไปยังการตั้งค่าของส่วนนั้น

cites:>100 cites:>=50 cites:<10

เกณฑ์จำนวนการอ้างอิง

เก็บเฉพาะบทความที่มีการอ้างอิงมากกว่าหรือน้อยกว่าตัวเลขใดก็ได้ที่คุณพิมพ์

ccf:a ccf:b core:a*

ระดับอันดับของแหล่งตีพิมพ์

แสดงเฉพาะบทความในการประชุมและวารสารที่มีอันดับ CCF หรือ CORE

role:first role:last role:cofirst

บทบาทผู้เขียน

กรองตามผู้เขียนคนแรก ผู้เขียนร่วมคนแรก ผู้เขียนคนที่สอง หรือผู้เขียนคนสุดท้าย (อาวุโส)

year:>2020 year:>=2021 year:<=2015

ปีที่ตีพิมพ์

บทความที่ตีพิมพ์หลัง ก่อน หรือภายในช่วงปีที่คุณเลือก หรือในช่วงห้าปีล่าสุด

has:award has:talk

รางวัลและการนำเสนอ

ค้นหาบทความ Best Paper, Test of Time, Oral, Spotlight และ Highlight

Escape

รีเซ็ตด้วยปุ่มเดียว

ล้างการค้นหา การเลือกในตาราง และตัวกรองทั้งหมดพร้อมกัน

ทุกบทความ ระบายสีตามบทบาทของคุณ

แถวของผู้เขียนคนแรก ผู้เขียนร่วมคนแรก ผู้เขียนคนที่สอง และผู้เขียนคนสุดท้าย แต่ละแถวมีสีของตัวเอง และชื่อของคุณจะถูกทำเครื่องหมายในบรรทัดผู้เขียน

อันดับ CCF และ CORE

อันดับ CCF 2026 และ ICORE 2026 แสดงข้างแหล่งตีพิมพ์แต่ละแห่ง พร้อมกฎที่จับคู่ได้ แหล่งที่ระบุไม่ได้จะไม่มีป้าย: ไม่มีการเดาเด็ดขาด

ตารางบทบาท × อันดับ

เลือกช่องหนึ่งเพื่อแสดงเฉพาะบทความในช่องนั้น และคัดลอกสรุปหรือรายการไปใส่ใน CV หรือแบบฟอร์มขอทุนได้

รางวัลและการนำเสนอ

บทความดีเด่น รางวัล Test of Time Oral, Spotlight และ Highlight จากคำพูดของผู้เขียนเอง และจากหน้ารางวัลทางการของบทความกว่า 7,000 เรื่อง

รายชื่อผู้เขียนที่ถูกตัด ทำให้ครบ

Scholar ซ่อนผู้เขียนท้าย ๆ ของรายชื่อที่ยาว คลิกเดียวก็อ่านรายชื่อเหล่านั้นจากหน้าของบทความ หรือจาก Semantic Scholar หากคุณอนุญาต

รวมรายการซ้ำ

หากเปิดใช้ รายการที่ระบุบทความเดียวกันสองครั้งจะรวมเป็นรายการเดียว และนับจำนวนการอ้างอิงรวมกัน

ปรับให้เป็นของคุณ

เลือกสิ่งที่จะแสดง เลือกสีของคุณเอง และซ่อนส่วนของหน้า Scholar ที่คุณไม่ต้องการ

ความเป็นส่วนตัวตั้งแต่การออกแบบ

ไม่ต้องมีบัญชี ไม่เก็บข้อมูลการใช้งาน ไม่มีการติดตาม ทุกการคำนวณเกิดขึ้นในเบราว์เซอร์ของคุณ และรายการอันดับมาพร้อมกับส่วนขยาย

ตัวเลขสำคัญ

ตัวเลขเหล่านี้นับจากโค้ดและข้อมูลของส่วนขยายตอนสร้างหน้านี้ ไม่มีตัวเลขใดพิมพ์ด้วยมือ และตัวเลขที่เพิ่มขึ้นทุกครั้งที่มีการแก้ไขจะปัดเศษลง

ติดตั้ง

  1. ดาวน์โหลดโปรเจกต์จาก GitHub (ปุ่มสีเขียว “Code” แล้วเลือก “Download ZIP”) และแตกไฟล์
  2. เปิด chrome://extensions แล้วเปิด “โหมดนักพัฒนาซอฟต์แวร์” (Developer mode)
  3. คลิก “โหลดแบบไม่แพ็ก” (Load unpacked) แล้วเลือกโฟลเดอร์ src จากนั้นเปิดโปรไฟล์ Google Scholar ใดก็ได้

อาจมีหน้ารายการใน Chrome Web Store ตามมาในภายหลัง Edge, Brave และเบราว์เซอร์ Chromium อื่น ๆ ใช้งานได้ในลักษณะเดียวกัน

ตรงไปตรงมาเกี่ยวกับข้อจำกัด

อันดับคือรายการในปัจจุบัน ไม่ใช่อันดับ ณ เวลาที่ตีพิมพ์ และตัวรายการ CCF เองก็ระบุว่าไม่ใช่การประเมิน ส่วนขยายไม่เคยเดาแหล่งตีพิมพ์: สิ่งที่ระบุไม่ได้จะแสดงในรายการ ไม่ได้ทำเครื่องหมาย
