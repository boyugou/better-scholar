# Screenshots and promo images

The images and their description live with the agent that makes them: `store/chrome/images/README.md` in its worktree
(`.claude/worktrees/agent-adbe7487bbd09334f/`), generated by `scripts/store-images.mjs`. `listing.md` uses that README's
captions and order. Checked on 2026-10-15.

All eight files have the sizes the store asks for (screenshots 1280×800, small tile 440×280, marquee 1400×560, icon
128×128 PNG); see the table in `listing.md`. What does not match:

1. **Wrong version (blocker).** The image worktree is at 2.38.1 (its `src/manifest.json`), without `content/bridge.js`,
   `lib/agent.js`, `lib/formats.js` and `lib/query.js`. Screenshot 5 shows the 2.38.1 popup: seven copy buttons
   (summary, table, BibTeX, Markdown, APA, JSON, CSV). In 2.39.0 the popup has eight, in this order: summary, table,
   papers, APA, BibTeX, Markdown, JSON, CSV (`src/lib/prefs.js:69-76`). The caption "with the same copy and export" is
   only true of 2.39.0. Rebase the image branch on the commit you submit and run the generator again; check the
   settings page in screenshot 4 too, since 2.39.0 reworked it (`CHANGELOG.md` 2.39.0).
2. **How to run it.** The image README says `npm run store:images`, but that worktree's `package.json` has no such script;
   `node scripts/store-images.mjs` is what exists.
3. **Caption 1** says "each venue marked with today's CCF and CORE rank". Only venues on the two lists get a chip, and the
   same screenshot shows rows without one (Findings of ACL, arXiv). Suggested: "venues marked with today's CCF and CORE
   rank".
4. **Caption 4** says "Every role, colour and part of the panel has its own switch". Roles and panel parts have switches;
   colours have pickers and themes. Suggested: "Every role and part of the panel has its own switch; colours are yours to
   pick, with a live preview."
5. Guidance only, not a rule: the small tile carries the name and a line of text (the image guide says "Avoid text"), and
   the icon's artwork fills the square instead of 96×96 with 16 px of transparent padding.
6. For Microsoft Edge: its large promotional tile must be a 1400×560 **PNG**; `promo-marquee.jpg` needs converting. Edge
   takes up to 6 screenshots at 640×480 or 1280×800, so the five here fit.
