一鍵匯出學術成果

可直接貼上的論文清單，適用於履歷、研究計畫申請表、LaTeX 文件、AI 代理程式與試算表。

即時搜尋與查詢運算符

在 Scholar 個人檔案的任何位置按 / 鍵，即可一次搜尋整份清單。

>100 >=50 <10

引用次數門檻

輸入任意數字，保留引用次數高於或低於該值的論文。

ccf:a ccf:b core:a*

期刊會議等級

只顯示發表於 CCF 或 CORE 評級之會議與期刊的論文。

role:first role:last r:cofirst

作者角色

依第一作者、共同第一作者、第二作者或末位（資深）作者篩選。

>2020 year:>=2021

發表年份

篩選在所選年份之後、之前或期間發表的論文。

has:award has:talk

獎項與演講

找出 Best Paper、時間考驗獎、Oral、Spotlight 與 Highlight 論文。

Escape

一鍵重設

一次清除所有搜尋、表格選取與篩選條件。

每篇論文，依你的角色著色

第一、共同第一、第二與末位作者的列各有一種顏色，你的名字會在作者列中標示出來。

CCF 與 CORE 等級

每個場所旁顯示 CCF 2026 與 ICORE 2026 的等級，並附上比對所依據的規則。無法判定的場所不做標示：絕不臆測。

角色 × 等級表

點選任一格即可只列出該類論文，並可複製彙整或清單，用於履歷或研究計畫申請表。

獎項與演講

最佳論文、時間考驗獎，以及 Oral、Spotlight、Highlight，資料來自作者本人的說明，以及超過 7,000 篇論文的官方獎項頁面。

補全被隱藏的作者列表

Scholar 會隱藏長作者列表的末位作者。按一下即可從論文頁面讀取，若你允許，也可從 Semantic Scholar 讀取。

合併重複條目

開啟後，列出同一篇論文兩次的條目會合併為一筆，引用次數加總。

由你自訂

選擇顯示內容、自選顏色，並隱藏你不需要的 Scholar 頁面部分。

設計上即保護隱私

無需帳號，沒有分析工具，也沒有追蹤。所有運算都在你的瀏覽器中完成，等級名單隨擴充功能一併提供。

安裝

  1. 從 GitHub 下載專案（點選綠色的「Code」按鈕，再選擇「Download ZIP」），然後解壓縮。
  2. 開啟 chrome://extensions，並開啟「開發人員模式」。
  3. 點選「載入未封裝項目」，選擇 src 資料夾。然後開啟任一 Google Scholar 個人頁面。

之後可能會上架 Chrome 線上應用程式商店。Edge、Brave 及其他 Chromium 瀏覽器的安裝方式相同。

坦白說明其限制

等級採用的是目前的名單，而非發表當時的等級；CCF 名單本身也聲明它並非學術評鑑。擴充功能從不臆測場所：無法判定的會列出，但不加標示。
