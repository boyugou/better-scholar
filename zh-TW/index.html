你在每篇論文中的位次與發表處等級

一款免費的 Chrome 擴充功能，適用於 Google Scholar 作者頁面。它依你的作者位次為每篇論文著色，顯示其發表處的 CCF 與 CORE 等級，並以一張表格統計你的論文。

獲獎與報告形式

最佳論文、時間考驗獎，以及 Oral、Spotlight 或 Highlight 報告的標籤。資料來自作者本人的說明和官方獎項頁面。

完整的作者列表

Scholar 會以「…」截短較長的作者列表，這可能會隱藏你的位次。按一下即可從 Scholar 的論文頁面讀取完整列表。

合併重複項目

Scholar 有時會把同一篇論文列出兩次。開啟開關後，這些項目會合併為一筆，引用次數加總。

檢查發表處

貼上一行發表處，即可查看 CCF 和 CORE 清單如何為它排定等級，以及依據哪條規則。清單未能涵蓋的發表處，你可以自行關聯到清單中的發表處：它的標籤會變為虛線框，每份複製內容都會標示。

表格轉為圖片

一鍵即可將你的位次×等級表複製為圖片放到剪貼簿，用於投影片、履歷，或接受圖片的表單。

面向 AI 代理

瀏覽用的 AI 代理可以讀取頁面上的計數和論文，並透過一組有文件說明的呼叫複製任何格式。它無法更改你的設定。

自訂版面

面板的每個部分都有自己的開關。可以選擇顏色、各部分的順序，以及為它們取你自己的名稱。

保護隱私

無需帳號，沒有分析工具，也沒有追蹤。所有工作都在你的瀏覽器中完成，等級清單都收錄在擴充功能裡。

30 種介面語言

擴充功能支援你的語言。它也能以你選擇的語言開啟 Scholar 本身。

試用設定頁面

這是擴充功能真正的設定頁面。變更一項設定，預覽就隨之改變。將滑鼠指向預覽中的某個部分，即可隱藏、移動或重新命名它。

跳過示範

用運算子搜尋

在作者頁面上按 / 鍵，即可搜尋其全部論文。在搜尋字詞中加入運算子，即可篩選清單。

cites:>100 cites:>=50 cites:<10

引用次數

引用次數高於或低於某個數字的論文。

ccf:a core:a* type:journal

等級

發表於指定 CCF 或 CORE 等級發表處的論文，或僅限期刊或僅限會議的論文。

role:first role:last role:cofirst

位次

你是第一作者、共同第一作者、第二作者或最後作者的論文。

year:>=2020 year:2023 age:<5

年份

發表於某一年之前、之後或當年的論文，或近幾年發表的論文。

has:award has:talk

獲獎與報告形式

獲得最佳論文獎或時間考驗獎的論文，以及有 Oral、Spotlight 或 Highlight 報告的論文。

Escape

全部清除

按一個鍵即可清除搜尋、選取的儲存格和所有篩選條件。

安裝

  1. 從 GitHub 下載專案：點選綠色的「Code」按鈕，再選擇「Download ZIP」。然後解壓縮檔案。
  2. 開啟 chrome://extensions，並開啟「開發人員模式」。
  3. 點選「載入未封裝項目」，選擇 src 資料夾。然後開啟一個 Google Scholar 個人頁面。

Edge、Brave 及其他 Chromium 瀏覽器的安裝步驟相同。之後可能會有 Chrome 線上應用程式商店版本。

限制

  • 等級取自目前的清單。論文發表當年，其發表處的等級可能不同。
  • CCF 表示，其清單不應作為學術評價的依據。
  • 它從不猜測。無法判定等級的發表處不顯示標籤，並會列在面板中。
